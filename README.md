Job Tracker - приложение на Python для чтения, валидации и фильтрации базы IT-вакансий из JSON-файла».

### Клонировать репозиторий
git clone <url>
cd job-tracker

### Установить зависимости
uv sync

### Команды CLI 
- list - показать список вакансий

  Опции: --limit (сколько показать), --status (фильтр по open/closed).

- move - сменить статус отклика
 
  Аргументы: vacancy_id (ID вакансии), new_status (новый статус)

- demo - демонстрация полного сценария 

### Стиль коммитов
Формат: тип(область): описание

Типы:
- feat - новая функциональность
- fix - исправление бага
- docs - документация
- refactor - рефакторинг без изменения поведения
- test - тесты
- ci - CI/CD
- chore - обслуживание (зависимости, конфиги)
