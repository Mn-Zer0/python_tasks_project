Job Tracker - приложение на Python для чтения, валидации и фильтрации базы IT-вакансий из JSON-файла».

### Стиль коммитов
Формат: тип(область): описание

Типы:
- feat - новая функциональность
- fix - исправление бага
- docs - документация
- refactor - рефакторинг без изменения поведения
- test - тесты
- ci - CI/CD
- chore - обслуживание (зависимости, конфиги)
